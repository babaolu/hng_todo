# Deploy rules

- Pushing to `main` deploys production via Vercel's GitHub integration. Don't use the Vercel CLI (`vercel link`, `vercel env`, `vercel deploy`).
- Migrations never run on push. If a change includes a migration, run `pnpm db:migrate:prod` **before** pushing, and only for additive changes (new tables, nullable or defaulted columns, indexes). Anything destructive (dropping or renaming columns or tables, narrowing types) must be flagged to the owner first. Don't run it.
- Production targets are explicit: `pnpm db:migrate:prod`, `pnpm seed:user:prod` and `pnpm user:add:prod` read `.env.prod`. The plain versions read `.env` (local PGlite). All of them print the database host they used; check it.
- Production database access is only through those explicit `:prod` scripts. Never run `pnpm preview`, `vite build` or any other production-mode command with production credentials: they run the server's start-up code against whatever database they're given. Production credentials live only in `.env.prod`, a name Vite never loads on its own; never rename or copy them to `.env.production*` or `.env.local`.
- Extra accounts: `pnpm user:add:prod` (create-only) or `pnpm user:add:prod --reset` (existing account only), using `NEW_USER_EMAIL` / `NEW_USER_PASSWORD`. Never use `seed:user` to add people, because it overwrites. Remove the `NEW_USER_*` lines (and any `ADMIN_PASSWORD`) from `.env.prod` afterwards.
- Never commit `.env*` files (except `.env.example`). The only secret in Vercel is `DATABASE_URL` (plus the non-secret `GUEST_MODE` switch when guest mode is wanted); never add `ADMIN_*` or `NEW_USER_*` variables there.
- Before calling work done: `pnpm check` and `pnpm test` pass.
- Guest mode: `GUEST_MODE=on` enables temporary guest accounts. Only an explicit `GUEST_MODE=off` deletes guests (all of them); unset or any other value just disables guests and deletes nothing. No guest cleanup ever runs during a build. Every guest cleanup must be filtered on `is_guest = true`. Real accounts must never be affected: `src/lib/server/guests.test.ts`, `guest-mode.test.ts` and `guest-flow.test.ts` check this.
